2)Student Operating System

A Student Operating System is a student-focused digital platform designed to organize and simplify academic life in one place. The project focuses on improving productivity and time management by bringing essential student tools together into a single system. Built using modern web technologies, it demonstrates practical skills in HTML, CSS, JavaScript, responsive design, and user-focused interface development.
